# Deck text extracts

Text of the source decks, extracted slide by slide so that sessions without access to the original
files (for example cloud sessions) can read the content. Images and layouts are not included. Facts on the
site must come from here or from docs/PRODUCT.md; never invent figures. Client-specific decks (proposals with
pricing, a client company deck) are deliberately not included.
